# C Multiplication Table

## Explanation

This program generates the multiplication table of a number entered by the user.

It uses a for loop to repeatedly multiply the given number by values from 1 to 10.

## Problem Statement

Write a C program to accept a number and display its multiplication table from 1 to 10.

## Features

- Accepts a number
- Generates multiplication table
- Uses for loop
- Performs repeated multiplication
- Displays results in an organized format

## How It Works

The program reads a number from the user.

A for loop starts from 1 and continues until 10.

During each iteration the given number is multiplied by the current loop value.

The result is displayed using printf().
